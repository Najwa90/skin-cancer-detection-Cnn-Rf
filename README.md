# Skin Cancer Detection using CNN, PCA, and Random Forest

## Overview
This project presents a hybrid skin cancer classification framework that combines Convolutional Neural Networks (CNN) for deep feature extraction, Principal Component Analysis (PCA) for dimensionality reduction, and a Random Forest classifier for final prediction.

## Features
- Image preprocessing
- Data augmentation
-class balancing using SMOTEENN
- Feature extraction using CNN
- Dimensionality reduction using PCA
- Random Forest classification
- Hyperparameter tuning
- Model evaluation
- Confusion Matrix
- Classification Report 


## Pipeline
1. Image preprocessing
2. Data augmentation
3. CNN feature extraction
4. PCA dimensionality reduction
5. Random Forest classification
6. Performance evaluation

## Technologies
- Python
- TensorFlow / Keras
- Scikit-learn
- NumPy
- Pandas
- Matplotlib
- Seaborn

## Dataset
HAM10000 Skin Lesion Dataset

## Results
The proposed hybrid CNN–PCA–Random Forest model achieved an overall classification accuracy of **97%** on the HAM10000 skin lesion dataset.

### Performance
- Accuracy: **97%**
- CNN for deep feature extraction
- PCA for dimensionality reduction
- Random Forest for final classification
